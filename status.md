# Game Status

Completion audit of all games in this repo, based on each game's own game-plan.md / CHANGELOG.md / PHASE-COMPLETE docs cross-checked against code. Ratings reflect feature completeness against each game's own stated scope, not code quality or bugs.

**Early-games refresh (2026-10-04):** games 001–036 were audited against the conventions the later games share ([docs/refresh-plan.md](docs/refresh-plan.md)). All of them now pass [`dev/smoketest.mjs`](dev/README.md) on desktop and on a touch-only phone, and with `localStorage` blocked (nine used to crash). All of them silence their audio in a hidden tab, and the layout bugs in 002, 005, 006, 026, 030 and 031 are fixed.

**Launcher note:** all 66 games are present in `js/gamedata.js` and appear on the home page, now a walkable 3D garden where each game has a statue placed by its `genre` field (the old card grid is `classic.html`). Two historical gaps, both now fixed and committed: game-030 (Coppergate Lane) was built but missing from `gamedata.js` entirely, and game-038 (Emberbrood) was listed but had no `.game-card.emberbrood .play-button` rule in `css/styles.css`, so its card fell back to the default button styling while every other game had a themed one.

## Key takeaways

- **Most finished:** game-008, 010, 011, 016, 020, 021, 023, 025, 031, 033, 037, 038, 039, 040 — all self-declared complete and verified against code with no meaningful gaps. The five most recent (033, 037, 038, 039, 040) are also the best-tested things in the repo: each ships a harness that runs its real logic outside a browser; 033 and 039 were both re-run as part of an earlier audit (109/109 and all harnesses green), and 040 ships five harnesses covering structure, simulation, rendering, boot flow and balance.
- **Real functional gaps (not just polish):** none left. The two games that were unfinished at a functional level both got there in the early-games refresh ([docs/refresh-plan.md](docs/refresh-plan.md)): game-022 (Depths Unknown) now ends when the Singing Vein is brought home, and game-032 (Ironhollow Depths) has ten floors, three enemy types and a win.
- **Doc/code mismatches worth knowing about:** game-006, game-009, game-012, game-014, and game-019 have plan docs that *understate* real progress — the code is further along than the checklists suggest. game-032 does the same in miniature (header still reads "Planning — Phase 1" though every Phase 1 item is checked off), but there the checklist below it is accurate and the game really is only Phase 1.
- **Recently landed, not yet eyeballed:** game-029's latest batch (new `fx.js`, monster archetypes, town/shop rework) is now committed, but its own plan doc flags it as not yet visually verified live in a browser — worth a playtest pass before considering Phase 3 fully closed.
