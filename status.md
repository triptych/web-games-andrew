## Key takeaways

- **Most finished:** game-008, 010, 011, 016, 020, 021, 023, 025, 031, 033, 037, 038, 039 — all self-declared complete and verified against code with no meaningful gaps. The four most recent (033, 037, 038, 039) are also the best-tested things in the repo: each ships a harness that runs its real logic outside a browser, and 033 and 039 were both re-run as part of this audit (109/109 and all harnesses green).
- **Real functional gaps (not just polish):** two games are unfinished at a functional level rather than merely missing stretch polish. game-022 (Depths Unknown) has no win condition. game-032 (Ironhollow Depths) never got past Phase 1 — it tracks a dungeon `level` internally but has no stairs tile to descend, so the counter never moves and there is neither progression nor an ending; it is also the only game in the repo with a single enemy type.
- **Doc/code mismatches worth knowing about:** game-006, game-009, game-012, game-014, and game-019 have plan docs that *understate* real progress — the code is further along than the checklists suggest. game-032 does the same in miniature (header still reads "Planning — Phase 1" though every Phase 1 item is checked off), but there the checklist below it is accurate and the game really is only Phase 1.
- **Recently landed, not yet eyeballed:** game-029's latest batch (new `fx.js`, monster archetypes, town/shop rework) is now committed, but its own plan doc flags it as not yet visually verified live in a browser — worth a playtest pass before considering Phase 3 fully closed.
