# Game Status

Completion audit of all games in this repo, based on each game's own game-plan.md / CHANGELOG.md / PHASE-COMPLETE docs cross-checked against code. Ratings reflect feature completeness against each game's own stated scope, not code quality or bugs.

**Early-games refresh (2026-10-04):** games 001–036 were audited against the conventions the later games share ([docs/refresh-plan.md](docs/refresh-plan.md)). All of them now pass [`dev/smoketest.mjs`](dev/README.md) on desktop and on a touch-only phone, and with `localStorage` blocked (nine used to crash). All of them silence their audio in a hidden tab, and the layout bugs in 002, 005, 006, 026, 030 and 031 are fixed.

**Launcher note:** all 87 games are present in `js/gamedata.js` and appear on the home page, now a walkable 3D garden where each game has a statue placed by its `genre` field (the old card grid is `classic.html`). Two historical gaps, both now fixed and committed: game-030 (Coppergate Lane) was built but missing from `gamedata.js` entirely, and game-038 (Emberbrood) was listed but had no `.game-card.emberbrood .play-button` rule in `css/styles.css`, so its card fell back to the default button styling while every other game had a themed one.
