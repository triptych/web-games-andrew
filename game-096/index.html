How to Play

Arrows / WASDRun
Space / ZJump (hold for higher)
X / JSpin: smash crates and baddies
C / L / ShiftShell power (hold if it says so)
Q / E, 1–5Swap shells
P / EscPause

    Touch: drag on the left to run. Jump, Spin and Power on the right; the little shell button swaps. Gamepad: stick, A jump, X spin, B power, bumpers swap.
