How to play

The VESTA-8 came out of the ground with eight broken cartridges, each a tiny toy version of a game that made history. Open one on the Workbench, use the tools to repair it, and Play it on the television. Every cartridge you restore gives the console back a piece of itself: colours, sound, music, new powers for your own games.

The Studio is the same toolkit with no checklist: make any 2D game you like and export it as a single HTML file that plays anywhere.
